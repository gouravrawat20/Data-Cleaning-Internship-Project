# Data Cleaning and Pre-processing Project

## Project Overview
In this project, I worked on a messy employee dataset and performed data cleaning and preprocessing using Python and Pandas. My goal was to improve data quality and make the dataset suitable for further analysis.

## Dataset Information
- Total Records: 1,020
- Total Columns: 12
- Dataset: Employee Dataset

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Data Cleaning Tasks
- Checked missing values
- Identified duplicate records
- Checked duplicate Employee IDs
- Handled missing Age and Salary using median imputation
- Standardized categorical values
- Removed extra whitespace from text columns
- Converted Join_Date into datetime format
- Validated email addresses
- Checked phone number formats
- Analyzed outliers using IQR method
- Performed final data quality checks

## Results
- Missing values in Age and Salary were handled.
- No duplicate rows or Employee IDs were found.
- No outliers were detected in Age and Salary using the IQR method.
- Email validation found no invalid email addresses.
- Phone number values required further source verification.
- Cleaned dataset was exported to CSV format.

This project helped me practice data cleaning and preprocessing techniques using Python. I learned how to identify data quality issues, handle missing values, validate data, and prepare a dataset for further analysis.
